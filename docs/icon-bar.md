# Icon bar and menus

## The icon bar

Below the menu: one icon per tool. Pane icons are **toggles** — pressed while the pane is open, click again to
close it. Tool icons are greyed out when the tool can't be used right now (e.g. Copy Last Command without a
PuTTY tab).

## Choose your icons

Right-click the icon bar → **Customize Icon Bar…** (also **View → Toolbars → Customize Icon Bar…**).

- **Checked** tools are shown, in the order of the list; unchecked ones are hidden.
- **Move Up / Move Down** change the order.
- **Add Separator** inserts a divider after the selected entry; uncheck a separator to drop it.
- **Reset to Default** brings back the standard bar.

Available tools: Sessions, Session Detail, Host Info, Layouts, Commands, Containers, Log Viewer, Open Session,
Recent Sessions, Copy Session, Copy Last Command, Explain in Claude, Open Session Log, Open Log Folder, Upload
Files, Transfer Files, SSH Tunnels, Run on Hosts, PuTTY Configuration, Options, Kiosk Mode.

The choice is stored in your settings and survives updates.

## Other toolbars

**View → Toolbars** switches the icon bar and the [command bar](command-bar.md) on or off. The menu bar and the
status bar can be hidden under **View** as well.

## Keyboard shortcuts

**Tools → Options → Shortcuts** assigns keys to actions (open session, switch tab, copy session, kiosk mode
…). ++f11++ toggles kiosk mode, ++f2++ opens the options, ++f1++ opens the help for the current pane.
